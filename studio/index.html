請熟客轉介紹，和附近店家交換小卡

熟客提到朋友也想做臉時，傳一段方便轉貼的店卡文案。顧客已在詢問某個搭配時，可以用上方的護理推薦卡，把項目與金額一次說清楚。

如果朋友在找台中東區的臉部養護，歡迎轉傳這張 Nihe 店卡。裡面有護理項目和價目，採預約制，可以從店卡加入 LINE 問時段。

也可以先找一家熟悉的東區美甲店、髮廊或美睫店，雙方同意後互放一張印有顧客店卡 QR Code 的小卡，試放兩週。

有空檔時，再試活動卡或 LINE 優惠
  • 有確定的空檔時，用活動卡寫清楚可約日期、護理內容和詢問期限，分享給曾問過相近時段的顧客。
  • 想測試首訪或好友推薦優惠時，再到 LINE 後台設定優惠券，先定好適用項目、期限和可接的人數。
  • 有穩定回訪再考慮集點，先算好能提供的回饋。能穩定接新客、知道詢問如何轉成預約後，再評估加好友廣告和帳號資格。
